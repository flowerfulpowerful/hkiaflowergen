How to Use
Getting Started
  1. Customize Grid: Click "Customize" to open the grid details panel and access other settings.
  2. Place Flower: Click on any empty grid cell to place your flower.
  3. Select Flower: Choose your flower type, primary color, pattern/effect, and secondary color.
  4. Analyze Results: Use "Analyze Flowers" to see breeding possibilities and percentages for the entire grid.
  5. View Details: Click on any cell in View Mode to see detailed breeding information for that individual cell.
Paint Mode
  • Enable Paint Mode: Toggle the switch to activate paint mode.
  • Disable Plots: Click empty cells to make them non-plantable.
  • Copy Flowers: Click a flower to copy it, then click another empty cell to paste the copied flower.
  • Create Patterns: Use paint mode to create symmetrical designs.
Edit vs View Mode
  • Edit Mode (Default): This is the main mode for designing your garden. You can place flowers, modify existing flowers, and use paint mode to create patterns.
  • View Mode: Switch to this mode to analyze your garden in detail. Click any cell to see detailed breeding information, percentages, and possible outcomes for that specific location.
  • Mode Toggle: Use the Edit/View toggle switch in the control panel to switch between modes. The switch shows which mode is currently active.
  • Cell Analysis: In View Mode, clicking any cell opens a detailed modal showing all possible breeding outcomes, percentages, and flower combinations for that specific plot.
  • Planning Strategy: Use Edit Mode to design your layout, then switch to View Mode to analyze breeding possibilities before finalizing your garden design.
Analysis Features
  • Breeding Analysis: See all possible flowers and their exact breeding probabilities from your current setup. You can analyze the entire grid ("Analyze Flowers" button) or individual plots in "View" mode.
  • Breeding Details: In "View" mode, how much of the final spawn chance for that flower comes from a specific breeding category, including: Color Mix, Color Transfer, Pattern Transfer, and Single Clone.
  • Greenhouse Mode: Toggle for greenhouse breeding percentages (cannot toggle "ON" for event flowers or preset plot layouts).
  • Event Mode: Simulate special event flower breeding & toggle automatic 5% event flower spawning.
Grid Customization
  • Grid Size: Change from 1x1 to 10x10 in Settings
  • Plot Layouts: Choose from real game plot layouts
  • Custom Grid: Create your own custom layouts
  • Clear Grid: Use "Clear Grid" to start fresh
  • Mobile Optimization: Larger grids auto-adjust for mobile devices (use the arrows at the top of the grid to scroll left/right)
Flower Types
  • General Flowers: Available year-round in specific locations
  • Event Flowers: Only available during special events
  • Extreme Flowers: Found in challenging locations (The Moon, Crystal Caves, etc.)
  • Glossary: Use the Glossary to learn about all flower types and locations
Advanced Features
  • Import/Export: Save and share your garden designs
  • Dark Mode: Toggle dark theme in Settings
  • Sound Effects: Enable/disable audio feedback
  • Mobile Support: Optimized for touch devices
  • Responsive Design: Works on all screen sizes
Settings & Configuration
  • Settings Button: Located in the top navigation bar, opens the main settings panel where you can configure all aspects of the simulator.
  • Grid Settings: Change grid size (3x3 to 10x10), select real game plot layouts, or create custom layouts to match your in-game gardens.
  • Breeding Preferences: Toggle Greenhouse percentages and Event simulation for special breeding rates.
  • Event Simulation: Select specific events like "Month of Meh" or "Jam Jamboree" to simulate special breeding rates for event flowers like Eggworts or Petunias. Also toggle automatic 5% event flower spawning.
  • Appearance: Enable/disable sound effects, toggle dark mode, and customize the visual experience to your preference.
  • Data Management: Export your garden designs to share with others, or import designs from the community using the import/export features. Supports both code or shareable URL.
Tips & Tricks
  • Adjacent Cells: Green tint shows breedable adjacent cells
  • Pattern Recognition: Some patterns don't allow secondary colors (like, Glitter or Frost)
  • Glossary: Read and view detailed information about each flower type, locations, and patterns
  • Percentage Accuracy: All percentages include fertilizer calculations
  • Plot Planning: Use real plot layouts to plan your in-game gardens

Understanding the Glossary

The Flower Glossary shows detailed information about each flower type, including their locations, patterns, and native colors. Here's how to interpret the visual indicators:

Location Tags
SR Primary/Native Location

These are the locations where the flower naturally grows and spawns. They appear with a pink background and bold border.

G Compatible Location

These are locations where the flower can be grown through breeding or greenhouse cultivation, but doesn't naturally spawn.

Pattern Tags
Ombre Default Pattern

The flower's natural pattern that appears by default. Shown with a pink background and bold border.

Striped Compatible Pattern

Patterns that can be obtained through breeding or pattern transfer, but aren't the flower's natural pattern.

Flower Types
General

Available year-round in their native locations. Can be grown in greenhouses.

Event

Only available during special events. Can be grown in greenhouses after obtaining.

Extreme

Found in challenging locations like The Moon or Crystal Caves. Cannot be grown in greenhouses.

Understanding Icons

Icons appear next to flower names to quickly identify their type, patterns, and breeding sources. Multiple icons may appear together to give you complete information about each flower.

% = Contribution Share
Each percentage shows how much of the spawn chance for that flower comes from a specific breeding type or parent.
Example: Pattern Transfer: 51.6% → 51.6% of the chance comes from nearby flowers transferring their pattern.
