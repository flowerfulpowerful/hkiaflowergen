Latest Updates - Version 2.0.9

July 5, 2026 Updates

This update focuses on breeding accuracy — aligning the simulator with live game data (v2.17.1) and fixing how event flowers interact with normal breeding percentages. Thank you to everyone who reported numbers that looked off! ❤️

Breeding Accuracy (Live Game Data)
  • Breeding weights were slightly updated from data loaded and sourced from game v2.17.1 (clone, color mix, pattern transfer, color transfer, grow rates, and event chance).
  • Single-parent patterned clones used to apply a fallback chance (20%) to single-parent patterned clones, which inflated rare outcomes like Anemone, Red, Ombre, White by roughly 20×. We confirm single-parent breeding uses the actual weight (1%) — a much smaller weight — instead of the fallback chance (20%).
  • Live weight values (game v2.17.1) use the game's actual weights for breeding, grow rates, and event chance.
Event Flower Simulation
  • Event flower spawning now follows the game's three-way roulette: each plot rolls between Nothing, Breeding, and Event — not a separate stack of percentages on top of breeding.
  • Event flowers use a flat 5% spawn slot during their event — not neighbors × 10% × 5%. On an empty plot during an event, each default color is split 5% across all default colors.
  • There is no 95% breeding penalty when an event is active. Breeding outcomes keep their full weight; the 5% event chance comes out of the "nothing" slice instead of reducing breeding percentages.
  • No Spawn is now shown in per-plot View mode when the combined breed + event chance is below 100%.
Bug Fixes
  • Fixed inconsistent event dilution where some setups appeared affected by events and others were not, due to incorrect multiplicative event math.
  • Rare patterned clones now reset the secondary color to the default (White) instead of copying the parent's secondary (e.g. Ombre, White — not Ombre, Black).

We're still working on confirming the exact rules for certain game mechanics. This update is backed by live game logic. If you have any questions or feedback, please feel free to submit a report on our site under the "Feedback" button in the About menu.

Thank you for your continued support! ❤️

Welcome to the HKIA Flower Generator!

November 18, 2025 Welcome

Welcome to the Hello Kitty Island Adventure (HKIA) Flower Generator! We're so excited to have you here. This tool was created to help players plan, design, and optimize their flower breeding gardens in Hello Kitty Island Adventure.

What is the HKIA Flower Generator?

The HKIA Flower Generator is an interactive web application that simulates flower breeding mechanics from Hello Kitty Island Adventure. Whether you're a beginner just starting your flower breeding journey or an experienced breeder looking to optimize your gardens, this tool helps you:

  • Plan Your Gardens: Design flower layouts and see exactly what flowers can be bred in each plot
  • Calculate Percentages: View the exact chances of getting each flower based on your garden setup
  • Simulate Events: See how special in-game events affect your breeding chances
  • Match In-Game Plots: Use preset layouts that match actual in-game locations, or create custom grids
  • Share Your Designs: Export and import garden codes to share with friends and the community
Key Features:
  • Interactive Grid: Place flowers on a customizable grid that matches your in-game plots
  • View & Edit Modes: Switch between editing your garden and analyzing breeding percentages
  • Paint Mode: Quickly disable plots or copy flowers to create patterns and custom layouts
  • Greenhouse Simulation: Toggle between greenhouse and standard breeding percentages
  • Event Simulation: Simulate special events to see how they affect your breeding chances
  • Plot Layouts: Choose from many preset layouts matching in-game locations, or create your own custom grids
  • Glossary: Comprehensive reference guide for all flowers, locations, effects, and patterns
  • Import & Export: Save your garden designs and share them with others
Getting Started:

New to the tool? Here's how to get started:

  1. Visit the Simulator page to start designing your garden
  2. Choose a plot layout that matches your in-game location (or use a custom grid)
  3. Place flowers on the grid by clicking empty cells
  4. Switch to View Mode to see breeding percentages and possible outcomes
  5. Use the Settings menu to adjust greenhouse mode, events, and other preferences
  6. Check out our Tips posts for detailed guides on using each feature
About This Project:

This tool was created by @Auevi and contributors as a voluntary project for the Hello Kitty Island Adventure community. This project is an unofficial community project made by us, not affiliated with Sunblink or any of its affiliates. We're constantly working to improve the tool and add new features based on community feedback.

If you have questions, suggestions, or feedback, please use the "Feedback" button in the About menu. We love hearing from the community!

Happy breeding! 🌸🌺🌻

Percentage Toggle Guide - Understanding Flower Chances

August 7, 2025 Tips

Understanding flower percentages is key to successful breeding! The Percentage Toggle feature lets you switch between standard and greenhouse percentages to see your exact chances of getting each flower.

How It Works:

The percentage toggle is located in the Settings menu under "Preferences". It's a simple switch that controls how breeding percentages are calculated. When enabled, the system calculates percentages as if all flowers are growing in the greenhouse, which provides enhanced breeding chances. When disabled, it shows standard outdoor breeding percentages.

How to Use the Percentage Toggle:
  • Open the "Settings" menu from the main interface
  • Look for the "Greenhouse Percentages" toggle switch in the Preferences section
  • Greenhouse Percentages can also be toggled by clicking the toggle button in the main interface
  • Toggle the switch on (green) for greenhouse mode or off (gray) for standard mode
  • Greenhouse percentages are automatically enabled when you first visit the site
  • Note: The toggle is automatically disabled when using preset plot layouts or during event simulations
Standard Percentages:
  • Shows percentages for regular flower growing in any outdoor plot
  • These are the base chances for each flower type outside of the greenhouse
  • Calculated using standard breeding weights
  • Useful for understanding fundamental breeding mechanics
  • Good for learning how different plots affect flower chances
  • More accurate for players who primarily grow flowers outside of the greenhouse
Greenhouse Percentages:
  • Shows percentages as if you're growing in the greenhouse
  • These percentages reflect the enhanced chances from greenhouse growing
  • Accurate for players who primarily use the greenhouse
  • All event flowers are valid in greenhouse mode, regardless of active events
When to Use Each Mode:
  • Greenhouse Mode: Use when planning greenhouse gardens or if you mostly grow in the greenhouse. This is the default mode and works best for most players.
  • Standard Mode: Use when planning outdoor gardens or learning basic breeding mechanics. Also useful for understanding how neighbor bonuses affect breeding.
  • Comparison: Switch between modes to see how greenhouse affects your chances for specific flowers
  • Strategy Planning: Use both modes to plan the most efficient breeding strategy based on where you'll actually grow your flowers
Pro Tips:
  • Start with Greenhouse: Since it's the default, use greenhouse percentages for most planning. Most players use the greenhouse for breeding.
  • Compare Modes: Switch between modes to see which gives you better chances for specific flowers. Some flowers may have better odds in one mode.
  • Plan Your Strategy: Use the mode that matches your actual growing method. If you grow outdoors, use standard mode.
  • Learn the Differences: Understanding both modes helps you make informed breeding decisions and understand game mechanics better.
  • Optimize Your Garden: Use the mode that gives you the best chances for your target flowers. Greenhouse mode is usually better for rare flowers.
  • Check Mode Availability: Remember that greenhouse toggle is disabled for preset plot layouts and during event simulations.
Understanding the Percentages:
  • Higher Percentages: Better chances of getting that flower. Flowers with higher percentages are more likely to appear.
  • Lower Percentages: Rarer flowers that are harder to obtain. These require more breeding attempts or specific setups.
  • Zero Percentages: Flowers that aren't possible with your current setup. You may need to change your flower arrangement or add different parent flowers.
  • Mode Differences: Greenhouse often shows higher percentages for rare flowers because it removes neighbor dependency and uses pure breeding weights.

The Percentage Toggle helps you make informed decisions about your flower breeding strategy. Whether you're growing in the greenhouse or outdoors, understanding your chances is the key to creating the perfect garden!

Import & Export Guide - Share Your Flower Gardens!

August 7, 2025 Tips

Want to share your beautiful flower garden with friends or save your favorite layouts? The Import & Export feature lets you save and share your flower grids with just a few clicks!

How It Works:

The Import & Export system uses advanced compression to convert your entire garden layout into a compact code string. When you export, the system captures all flower data (types, colors, patterns, effects), grid dimensions, disabled cells, plot layout settings, and even your preferences (sound, greenhouse mode, event settings). This data is then compressed and encoded into a shareable string that can be easily copied and pasted. When importing, the system decompresses the code and recreates your exact garden layout, including all flowers in their precise positions.

How to Export Your Garden:
  • Create your perfect flower garden layout with all the flowers you want to save
  • Open the "Settings" menu from the main interface
  • Click the "Export Garden" button (look for the download/upward arrow icon)
  • Your grid code will automatically be copied to your clipboard
  • A notification will appear confirming the export was successful
  • You can now paste this code anywhere to share with others - in messages, forums, or save it in a document
  • The code works across different devices and browsers
How to Import a Garden:
  • Open the "Settings" menu from the main interface
  • Click the "Import Garden" button (look for the upload/downward arrow icon)
  • A text input box will appear where you can paste a grid code
  • Paste the code you received from a friend or saved previously
  • Click the "Submit" button to load the garden
  • Your flower garden will be instantly recreated with all flowers in their exact positions!
  • The system will also restore your saved settings (greenhouse mode, event settings, etc.)
  • Note: Importing will replace your current garden, so export first if you want to keep it!
What Gets Saved:
  • Flower Types: All flower varieties and their exact positions in the grid
  • Primary Colors: Every flower's main color information
  • Secondary Colors: Secondary color data for flowers with patterns that support it
  • Effects & Patterns: Special effects (like Molten, Cosmic, Crystal) and patterns (like Alternate, Pinwheel) on flowers
  • Disabled Cells: Which plots are disabled and won't generate flowers
  • Grid Dimensions: The size of your custom grid (rows and columns)
  • Plot Layout: Which preset plot layout you're using (if any)
  • Settings: Your preferences including sound settings, greenhouse mode, selected event, and event simulation status
  • Complete Garden State: Everything needed to perfectly recreate your garden
Pro Tips:
  • Backup Your Favorites: Export your best gardens to save them permanently. Keep a collection of your favorite breeding setups!
  • Share with Friends: Send grid codes to friends so they can recreate your gardens. Great for sharing successful breeding strategies!
  • Community Sharing: Share your codes on forums or social media to help other players. The community loves seeing creative garden designs!
  • Experiment Safely: Export before making major changes so you can always go back. This lets you try new layouts without fear of losing your work.
  • Collect Rare Gardens: Import codes from other players to discover new flower combinations and learn new breeding strategies.
  • Version Compatibility: The system supports importing codes from previous versions of the generator, so older codes still work!
  • Save Multiple Versions: Export different variations of your garden to compare strategies and outcomes.
Example Grid Code:

Grid codes look like this: H4sIAAAAAAAAA10qjlFKL8pMCc6sS...

These codes are compressed and encoded, making them compact and easy to share. They contain all the information needed to recreate your exact garden layout, including all flowers, colors, patterns, effects, and settings!

Troubleshooting:
  • Invalid Code: If you get an error when importing, make sure you copied the entire code without any extra spaces or characters
  • Missing Flowers: If some flowers don't appear after importing, they may not be valid for the current plot layout or event settings
  • Code Too Long: Very large gardens may produce longer codes, but they should still work. If you have issues, try exporting again

The Import & Export feature makes it easy to share your creativity with the Hello Kitty Island Adventure community. Save your favorite gardens, share them with friends, and discover amazing flower combinations from other players!

How to Use the Paint Tool - Complete Guide

August 7, 2025 Tips

The Paint Tool is one of the most powerful features in the HKIA Flower Generator! Use it to disable plots and copy/paste flowers to create your perfect garden layout.

How It Works:

Paint Mode has two distinct functions that you can switch between: Disable Mode and Copy Mode. When paint mode is enabled, clicking on cells will either disable/enable them (Disable Mode) or copy flowers from one cell to another (Copy Mode). The system remembers which flower you've selected for copying and will paste it to any empty cell you click. Disabled cells are excluded from all breeding calculations and won't generate flowers, making them perfect for creating custom layouts.

How to Enable Paint Mode:
  • Look for the "Paint Mode" button in your generator interface (usually near the top of the control panel)
  • Click the button to toggle paint mode on or off
  • When the button is green/highlighted, paint mode is enabled and ready to use
  • When paint mode is enabled, you'll see two indicator buttons appear: "Disable" and "Copy"
  • Click on either indicator to switch between Disable Mode and Copy Mode
  • Note: Paint mode automatically disables when you switch to View Mode
Disable Mode - Disabling Plots:
  • Enable paint mode and select "Disable" mode (the indicator will be highlighted)
  • Click on any empty plot to disable it - the plot will turn dark gray
  • Click on a disabled plot again to re-enable it - it will return to normal
  • Disabled plots won't generate flowers and won't be included in percentage calculations
  • This is perfect for creating custom garden layouts or focusing on specific areas
  • Disabled cells are saved when you export your garden
  • You can disable cells even if they have flowers in them - the flowers will be removed
Copy Mode - Copy/Paste Flowers:
  • Enable paint mode and select "Copy" mode (the indicator will be highlighted)
  • First, click on a plot that contains an existing flower - this selects it for copying
  • The system will remember this flower and all its properties (type, primary color, secondary color, pattern, effect)
  • Then click on any empty plot to paste the copied flower there
  • The flower will be duplicated with all its exact properties
  • You can continue clicking on more empty plots to paste the same flower multiple times
  • To copy a different flower, just click on another flower first, then paste it
  • This is great for creating symmetrical gardens or duplicating rare flowers quickly
How the Two Modes Work Together:
  • You can switch between Disable and Copy modes at any time while paint mode is active
  • Disable mode is perfect for setting up your garden layout by marking which plots to use
  • Copy mode is ideal for quickly filling your garden with specific flowers
  • You can use both modes in the same session - disable unwanted plots, then copy flowers to the enabled ones
Pro Tips:
  • Plan Your Layout: Use Disable mode to sketch out your garden design before placing flowers. This helps visualize your breeding setup.
  • Create Patterns: Use Copy mode to create beautiful symmetrical patterns by copying flowers to mirror positions
  • Focus Breeding: Disable unwanted plots to concentrate on specific flower combinations and improve your breeding efficiency
  • Experiment Freely: Paint mode lets you try different layouts without losing your work - you can always re-enable disabled cells
  • Quick Duplication: Copy mode is perfect for quickly setting up breeding pairs or creating multiple copies of rare flowers
  • Custom Grids: Combine Disable mode with custom grid sizes to create unique garden shapes and layouts
  • Save Your Work: Remember to export your garden after using paint mode to save your custom layout
Important Notes:
  • Paint mode is automatically disabled when you switch to View Mode
  • Disabled cells are excluded from all breeding calculations, so they won't affect percentages
  • You can't copy flowers to disabled cells - they must be enabled first
  • Copy mode only works on empty cells - to replace a flower, disable the cell first, then paste

The Paint Tool gives you complete control over your flower garden. Use it to create unique layouts, duplicate your favorite flowers, and design the perfect garden for your Hello Kitty Island Adventure!

View Mode vs Edit Mode - Understanding the Two Modes

November 18, 2025 Tips

The HKIA Flower Generator has two main modes that serve different purposes: Edit Mode and View Mode. Understanding when and how to use each mode will help you get the most out of the generator!

How It Works:

Edit Mode is the default mode where you can place, modify, and arrange flowers in your garden. View Mode is an analysis mode that lets you examine your garden and see detailed breeding information. The two modes are mutually exclusive - when you enable View Mode, Edit Mode (and Paint Mode) are automatically disabled, and vice versa. You can switch between modes at any time using the toggle switch in the control panel.

Edit Mode (Default):
  • Purpose: This is your main workspace for designing and building your garden
  • What You Can Do: Place new flowers, edit existing flowers, use paint mode to disable plots or copy flowers, and modify your garden layout
  • How to Use: Click on empty cells to open the flower selection modal and place flowers. Click on existing flowers to edit their properties (type, color, pattern, effect)
  • When to Use: Use Edit Mode when you're setting up your garden, making changes, or experimenting with different layouts
  • Features Available: All editing features including paint mode, flower placement, and garden modification
View Mode:
  • Purpose: Analyze your garden and see detailed breeding information without making changes
  • What You Can Do: Click on any cell to see detailed information about that plot, including breeding percentages, possible outcomes, and flower details
  • How to Use: Switch to View Mode using the toggle, then click on any cell in your garden to see a detailed information popup
  • When to Use: Use View Mode when you want to analyze your garden, check breeding percentages, or see what flowers are possible in specific plots
  • Features Available: Cell information display, percentage viewing, breeding analysis - but no editing capabilities
How to Switch Between Modes:
  • Look for the Edit/View Mode toggle switch in the control panel (usually near the top)
  • The switch shows "Edit Mode" when in edit mode and "View Mode" when in view mode
  • Click the toggle to switch between modes
  • When you switch to View Mode, Paint Mode is automatically disabled
  • When you switch back to Edit Mode, you can re-enable Paint Mode if needed
Pro Tips:
  • Design in Edit Mode: Use Edit Mode to build and modify your garden layout
  • Analyze in View Mode: Switch to View Mode to check your breeding percentages and see if your setup is working as expected
  • Iterate Between Modes: Switch back and forth between modes - design in Edit Mode, then check results in View Mode, then adjust in Edit Mode again
  • Check Before Breeding: Always check your garden in View Mode before implementing it in-game to ensure you're getting the percentages you want
  • Learn Breeding Mechanics: Use View Mode to understand how different flower arrangements affect breeding outcomes
What Information You See in View Mode:
  • Cell Details: Information about the selected cell including current flower (if any) and breeding possibilities
  • Breeding Percentages: The chances of getting each possible flower in that specific plot
  • Possible Outcomes: A list of all flowers that could appear in that plot based on neighboring flowers
  • Breeding Icons: Icons showing how each flower can be obtained (Color Mix, Color Transfer, Pattern Transfer, Single Clone)

Understanding the difference between Edit Mode and View Mode helps you work more efficiently. Use Edit Mode to build your garden, and View Mode to analyze and verify your breeding setup!

Event Simulation Guide - Simulating Special Events

November 18, 2025 Tips

The Event Simulator lets you see how special in-game events affect your flower breeding chances. This powerful feature helps you plan your breeding strategy during events!

How It Works:

When an event is selected, the simulator modifies breeding calculations to include event-specific mechanics. Event flowers can spawn naturally during active events, and breeding percentages are adjusted to reflect event bonuses. The system validates flowers based on whether the event is active - event flowers can only spawn naturally when their corresponding event is selected. When no event is active, event flowers won't appear in percentage lists unless you're using greenhouse mode.

How to Enable Event Simulation:
  • Open the "Settings" menu from the main interface
  • Navigate to the "Other" section
  • Look for the "Event" dropdown menu
  • Select an event from the dropdown (or choose "None" to disable event simulation)
  • Event Simulation can also be toggled by clicking the toggle button in the main interface
  • You can also toggle "Event Simulation" on or off to control whether event flowers spawn naturally
  • When an event is selected, the greenhouse toggle is automatically disabled (event simulations use their own breeding rules)
What Events Do:
  • Event Flower Spawning: When an event is active, the corresponding event flower can spawn naturally in your plots
  • Breeding Percentages: Event simulations adjust breeding percentages to reflect event-specific mechanics
  • Natural Spawning: Event flowers appear in percentage lists as possible outcomes when their event is active
  • Validation: The system validates flowers based on event status - event flowers are only valid when their event is active (unless in greenhouse mode)
Event Simulation Toggle:
  • Enabled: Event flowers will spawn naturally and be included in breeding calculations
  • Disabled: Event flowers won't spawn naturally, but you can still manually place them in your garden
  • Use Case: Toggle this off if you want to see percentages without event flower interference
Pro Tips:

  • Color Transfer Icon: This flower can be obtained through color transfer - transferring a color from one flower to another
  • Pattern Transfer Icon: This flower can be obtained through pattern transfer - transferring a pattern from one flower to another
  • Single Clone Icon: This flower can be obtained through single cloning - a flower can clone itself when bred alone or with compatible flowers

  • Use this information to plan the most efficient breeding path

  • Use Help Button: Click the Help button in the percentage view to see a detailed explanation of each icon
  • Plan Your Strategy: Use icon information to plan which parent flowers you need for your breeding setup
  • Understand Breeding Mechanics: Learning what each icon means helps you understand the game's breeding system better
How to Use This Information:
  • Color Mix: If you see this icon, you need two flowers with specific colors that will mix to create the target flower
  • Color Transfer: If you see this icon, you need a flower with the desired color to transfer it to another flower
  • Pattern Transfer: If you see this icon, you need a flower with the desired pattern to transfer it to another flower
