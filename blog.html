Latest Updates - Version 1.5.7

August 5, 2025 Updates

Welcome to the latest update of the HKIA Flower Generator! Version 1.5.7 brings several important improvements and new features:

Major Updates:

  • Plot Generation: Fixed incorrectly labeled plot generation options and added new flower plots (including Crystal Caves plot)
  • New Flowers & Patterns/Effects: Added Crystalia and Pinwheel flowers, plus Crystal effect and Alternate pattern
  • Invalid Flowers: Invalid flowers will now have a red outline around their plot for better visibility
  • Color Jump/Transfer: Implemented in-game changes where Color jump/transfer couldn't be done to other flowers if it could be reached via their default colors. Color jump/transfer will now be possible in these cases

Minor Tweaks:

  • Percentage List Changes: Removed the "None" text so that it's just empty if it's "None"
  • Percentage Accuracy: Fixed the percentages to be as accurate as possible (3 decimal points in specific plot % view)
  • Flower Effects: Fixed the Effect patterns (Molten wasn't an effect pattern for some reason)
  • Visual Improvements: Added a light gray horizontal bar for visual separation between flower percentages
